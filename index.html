宏观2 · B站财经视频 → 原子命题级证据链 → 可审计推理 SFT 数据集

把 B 站财经视频（UP 主「巫师财经」）的口播内容，抽成以「原子命题」为单位的证据链， 再逐链组织成可审计、可追溯、可拒答的推理 SFT 数据集。 —— 核心卖点是「证据链 + 审计治理 + 拒答」，而不是普通问答对生成。

原子命题 Claim 三链分层 主动拒答 9 项审核门禁 防泄漏与可复现 数据血缘纠错

02 · 与「普通视频转 QA」的区别

维度普通视频转 QA本项目
内容单位段落摘要原子命题（Claim） + 关系边（Edge）
作者观点当成事实显式区分「作者推断 / 作者结论 / 可核验事实」
结论来源模型自由生成三链分离（事实传导 / 作者推理 / 现实验证）+ 跨链对齐
答不出来编一个主动拒答（causal_conclusion="ABSTAIN"）
时序忽略时序（precedes）与因果（causes）分离
数据泄漏无意识14 文件输入冻结哈希 + 导出后复校验 + 训练输入字段黑名单

03 · 三链模型（三泳道）

① fact_transmission　事实传导链（8 步；CASE-VANKE 例外 9 步）
「外部世界发生了什么、怎么传导」
② author_reasoning　作者推理链（7 步）
「UP 主是怎么推断的（含其隐含假设）」
③ world_verification　现实验证链（8 步）
「用公开证据去验证作者的说法」

三链之间用 chain_alignments 做跨链对齐：fact_to_author_premise / evidence_to_claim / gap_blocks_inference / author_to_bounded_world。前端以三条泳道并排展示（[8, 7, 8]，万科 [9, 7, 8]）， 并用 Playwright 双视口断言「页面渲染的节点数」与「数据集里的节点数」一致。

04 · 核心机制

F / M / I / C / U 节点

可核验事实 / 传导机制 / 作者推断 / 作者结论 / 传闻缺证；Claim 用 frozen 定义，命题入库即不可变。

终态四态

answer / bounded_answer / boundary / abstain —— 把「能答多少、边界在哪」编码进输出契约。

9 项审核布尔门禁

含 author_claim_upgraded_to_world_fact（防把作者观点升格为事实）与 temporal_causal_confusion（防把时序当因果）。

防泄漏双向锁

14 文件 SHA-256 白名单 + 导出后复校验；训练输入字段黑名单（audit_context / mother_graph / terminal_kind）。

来源快照双哈希

snapshot_sha256 + content_sha256 双向锁定；快照文件名即内容 SHA-256（内容寻址）。

数据血缘纠错

发现 bug 不改原始数据，新增纠正记录（lineage_corrections=10），原始数据 immutable。
