# QA 推理链训练数据 V2：事件案例包

本数据集以可审计的事件案例包为核心资产。

## 真值边界

- `author_trace` 只表示作者推理的忠实还原，不表示现实因果成立。
- `world_evidence` 只允许陈述经过复核的外部证据实际覆盖范围。
- 数据只保存 claim、chain、context、source 与 evidence-link 引用，不保存模型自由式思维过程。

## 发布边界

- 公开文件只包含研究所需的短引文、定位信息、URL 和内容哈希。
- 不重新发布完整文章、完整文字稿、音频、视频、付费或受限页面正文。
- 品牌合作或赞助必须披露，并进入来源边界和替代解释审核。
- V1 test 事件簇及其重发、续篇和语义改写不得进入 V2 训练来源。

## 规模与维护

- 案例：2
- 上下文：12
- 外部证据链接：2
- 权利人提出合理下架请求或来源边界发生变化时，以新版本移除记录并更新哈希。
