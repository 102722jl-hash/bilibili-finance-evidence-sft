# 多任务证据推理训练集 V1

本数据集从 QA 推理链评测集 V1 的 approved dev 记录确定性派生，采用 messages 格式。

## 规模与用途

- 训练记录：23
- 每条记录同时监督答案、可回答性、有序推理引用和必要证据引用。
- 当前规模只是训练管线基线，不足以单独训练具备泛化能力的模型。

## 污染边界

- V1 dev 已被训练消费，不能继续作为无污染开发集。
- V1 test 未进入训练产物。
- 正式扩充必须采用独立事件簇和独立来源，不得改写 V1 test 样本后复用。

## 真值边界

- author_trace 只监督忠实还原作者推导，不代表现实因果成立。
- world_evidence 只监督外部证据实际覆盖范围。
- 证据不足必须拒答，未证实不等于已反驳。
